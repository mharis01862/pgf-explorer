# PGF-Explorer: Plant Gene Family Meta-Analysis Database

PGF-Explorer is an interactive, live exploration workspace for curated genome-wide gene family studies. It provides dynamic filters, trend intelligence, and paper-level deep dives designed specifically for researchers and bioinformatics professionals.

## Features
- **Live Filter Engine**: Instantly filter hundreds of papers by organism, gene family, year, and validation method.
- **Trend Intelligence**: Automatically generated charts visualizing publication trends, validation techniques, top organisms, and more.
- **Research-Grade Exports**: Export filtered datasets directly to CSV for downstream analysis or citation management.

## Repository Structure

- `assets/` - Contains the frontend CSS styles and JavaScript application logic.
- `data/` - Holds the processed JSON metadata files generated by the build script.
- `database/` - Contains the original PDF manuscripts.
- `docs/` - Contains database documentation, including schemas and data dictionaries.
- `raw_data/` - Contains the original raw CSV data sourced from the literature review.
- `scripts/` - Build scripts (`build-database.mjs`) and a local dev server (`serve-local.mjs`).

## Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) installed (v16 or higher recommended).

### Running Locally
1. Clone this repository to your local machine.
2. Run the local server to explore the database:
   ```bash
   npm run start
   ```
3. Open your browser to `http://127.0.0.1:4173/index.html`

### Rebuilding the Database
If you update the source CSV data in the parent directory, you can rebuild the `.json` data files using:
```bash
npm run build
```
