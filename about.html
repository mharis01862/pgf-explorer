About PGF-Explorer

An Interactive Database for Plant Gene Family Meta-Analysis

1. Purpose of This Database

The platform is an interactive research environment for curated plant genome-wide gene family studies. It is designed to support literature exploration, evidence tracking, cross-study comparison, and export-ready synthesis for academic writing and downstream analysis.

The Explorer is filter-first and evidence-oriented: every view can be narrowed by organism, gene family, year, journal, country, and validation evidence. Paper-level records remain linked to primary metadata and PDF access.

2. Current Application Modules

Explorer
Main interface for filtering, ranking, trend inspection, and paper review. Includes advanced query controls, compact/detailed views, and CSV export from the active filtered set.
Comparison Workspace
Select multiple papers and compare metadata side-by-side with shared-family, shared-organism, and shared-tool summaries.
Dataset Assistant
Bottom-corner agent-style assistant. It is grounded in the current filtered dataset view and returns evidence-backed answers with paper IDs.
Resources
Separate page for (i) all-paper BibTeX export, (ii) reproducibility package export, and (iii) database citation text for future publication release.

3. Data Pipeline and Structure

Source metadata are maintained in CSV and transformed into normalized JSON plus search-ready bundles for the web interface. The builder script materializes linked entities and denormalized search rows for fast browser-side interaction.

Primary Input
database/Data.csv (build source)
Derived Web Data
interactive_database_academic/data/*.json and bundle.js
Runtime PDF Library
interactive_database_academic/database/<PaperID>.pdf
Build Script
interactive_database_academic/scripts/build-database.mjs

4. Filtering, Evidence, and Ranking Logic

Records are filtered by direct field constraints and advanced controls (year range, evidence threshold, and keyword match mode). Ranking supports Paper ID sequence, chronology, title order, and gene-count prioritization.

Validation context is exposed at both card and detail level, with explicit flags for RNA-seq and RT-qPCR. Comparisons and assistant answers are derived from the same active filtered subset to keep interpretation consistent.

5. Chat Assistant Scope and Limitations

The assistant is designed as a dataset-native copilot, not a general internet chatbot. It answers from currently loaded records and filtered context only, then provides evidence snippets.

What it does well
Counts, summaries, top entities, high-evidence retrieval, recent-paper retrieval, and grounded synthesis from matched papers.
What it does not do
It does not query external databases or infer facts outside the current dataset. Unknown or unsupported queries are reported explicitly.

7. Recommended Use in Academic Work

For rigorous reporting, keep both the applied filter context and exported evidence identifiers (paper IDs) in your notes. When generating figures/tables, cite the export date and module used (Explorer filters, compare tray, or Resources package).

This resource is intended to accelerate synthesis and transparency, not replace full-text methodological review.
